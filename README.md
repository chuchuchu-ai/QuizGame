# QUIZ 40

처음 GitHub에 올리고 무료 웹사이트로 공개하려면 [단계별 배포 안내서](DEPLOYMENT.md)를 참고하세요. 문제별 사실관계와 검토 출처는 [콘텐츠 검토 문서](CONTENT_REVIEW.md)에 있습니다.

한국사·과학·지리·일반상식·세계사의 50문제 중 분야마다 8문제씩 뽑아 총 40문제를 푸는 상식 게임입니다.

## 실행 방법

VS Code 터미널에서 다음 명령을 순서대로 실행하세요. Node.js가 설치되어 있어야 합니다.

```powershell
# 퀴즈게임 프로젝트 폴더로 이동합니다.
cd E:\CodexProjects\QuizGame
# 필요한 도구를 이 프로젝트에 설치합니다. 최초 실행 시 사용합니다.
npm.cmd install
# 개발용 웹 서버를 실행합니다. 표시되는 주소를 브라우저에서 여세요.
npm.cmd run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. `npm` 실행이 허용된 터미널에서는 `npm install`, `npm run dev`도 동일하게 사용할 수 있습니다.

## 구현 내용

- 홈 → 5지선다 퀴즈 → 결과 → 랭킹 화면
- 게임마다 중복 없는 무작위 40문제, 분야별 8문제
- 정답당 10점, 최대 400점, 정오답 표시와 해설
- 답변 변경 및 중복 채점 방지
- 진행률, 정답률, 오답 수, 분야별 성적
- 닉네임 1~20자, 게임당 1회 기록 등록
- 점수 내림차순, 동점은 등록 시간 오름차순, 상위 100개 기록
- PC·태블릿·모바일 화면 대응, 키보드 조작, 색상과 글자로 정오답 구분

랭킹은 LocalStorage(현재 브라우저에 데이터를 보관하는 공간)에 저장합니다. 다른 기기·브라우저와 공유되지 않습니다. 브라우저 데이터를 삭제하면 랭킹도 사라집니다. 같은 주소와 포트로 접속해야 기존 기록이 보입니다. 새로고침하면 진행 중 게임은 초기화되며 저장한 랭킹은 유지됩니다. 저장 공간이 차거나 접근이 차단된 경우 안내 문구를 표시합니다. 손상된 저장 데이터는 임의로 덮어쓰지 않습니다.

## 검증 명령

```powershell
# TypeScript 코드 검사와 배포용 파일 생성을 실행합니다.
npm.cmd run build
# 출제·채점·랭킹 자동 검증을 실행합니다.
npm.cmd test
# 설치된 Microsoft Edge로 PC·모바일 크기에서 실제 게임 흐름을 검사합니다.
npx.cmd playwright test
# 실제 배포 파일이 저장소 하위 주소에서도 작동하는지 확인합니다. 먼저 build를 실행하세요.
npx.cmd playwright test --config playwright.production.config.ts
```

`dist`는 배포용 파일이 생성되는 폴더입니다. `npm run preview`로 배포용 결과를 확인할 수 있습니다. 브라우저 검증은 Microsoft Edge가 필요하며 휴대전화 화면 크기를 모의합니다.

## 파일 안내

- `src/data/questions.ts`: 50개 문제, 정답, 해설
- `src/utils/quiz.ts`: 무작위 출제, 채점, 진행, 분야별 결과
- `src/utils/ranking.ts`: 기록 검사, 저장, 정렬
- `src/pages/`: 홈, 퀴즈, 결과, 랭킹 화면
- `src/components/`: 문제 카드와 진행 막대
- `src/styles.css`: 화면 디자인과 모바일 대응
- `src/utils/quiz.test.ts`, `tests/game.spec.ts`: 자동 검증

회원가입, 온라인 공용 랭킹, 시간제한 등은 PRD의 MVP 범위에서 제외되어 있습니다.
